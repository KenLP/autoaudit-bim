# References — fixtures and templates

Sample inputs used by the tests and the extraction workflow.

| Path | What it is |
|---|---|
| `spec_fixtures/` | Building-code PDFs used as extraction fixtures. The files themselves are not committed (they are large and public-domain) — run `spec_fixtures/fetch.sh` to download them. |
| `templates/` | The rules-extraction prompt and a sample extracted-rules JSON envelope. |
| `demo_approvals/` | Approval records used by the `--demo` run. |
