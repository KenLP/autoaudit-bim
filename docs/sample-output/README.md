# Sample output

One real `--demo` run, committed so you can read what AutoAudit produces
before installing anything. Start with
[`verification_report.md`](verification_report.md) — the rest are the
artifacts it links to.

Reproduce it with:

```bash
uv run bim-orchestrator --demo
```

Verbatim apart from absolute machine paths and the operator/host names in the
provenance block, which identify the machine a run happened on and have no
business in a committed sample.
